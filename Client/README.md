# BuildNOVA Construction Ltd.

React + Vite frontend for a Smart Building Design & Construction Management System.

## 8 Core Features
1. Customer Registration & Login
2. Building Requirement Submission
3. Civil Engineer Matching & Selection
4. Customer ↔ Engineer Communication
5. Building Design & Cost Estimation
6. Project Progress Tracking
7. Project Schedule & Milestones
8. Feedback & Rating

## Run
```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal, usually http://localhost:5173

Note: This ZIP is the frontend prototype. Backend/API/MySQL can be connected next.
